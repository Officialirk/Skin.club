About & Disclaimer

What this tool is

{{ app_name }} is a local, offline statistics and decision-support utility for case-opening / loot-box style products. Given a list of possible items, their probabilities, and their market values for a "case", it computes:

  • Expected value (EV) and net EV per open
  • Return-to-player (RTP) percentage
  • Variance, standard deviation, and a coefficient-of-variation risk label
  • Probability of profit/loss on a single open
  • Monte Carlo simulated outcome ranges for repeated opens
  • A bankroll/risk-management plan from a budget and a maximum acceptable loss
  • A comparison of your own logged history against the theoretical EV

What this tool is not, and does not do

  • It does not scrape, connect to, or automate Skin.Club or any other site.
  • It does not place bets, open cases, deposit, withdraw, or perform any account action anywhere.
  • It does not attempt to predict, influence, or "beat" any random-number generator.
  • It cannot and does not guarantee any win, profit, or specific outcome.

Where case/item data comes from

{{ sourcing_note }}

The expected JSON shape for a case:

{
  "cases": [
    {
      "case_id": "unique-id",
      "name": "Display name",
      "price": 2.50,
      "currency": "USD",
      "source": "where you obtained these odds (a public page, your own account export, etc.)",
      "last_updated": "2026-08-01",
      "items": [
        { "name": "Item name", "rarity": "Rarity label", "probability": 0.05, "market_value": 3.20 }
      ]
    }
  ]
}

Item probabilities within a case must sum to 1.0 (small rounding error tolerated). Import via the box on the Cases page, or place a file at data/custom_cases.json.

Theoretical EV vs. actual results

Expected value is a long-run average over infinitely many opens. Over a small number of opens, actual results (variance) can differ substantially from the theoretical EV in either direction — that is normal and expected, not evidence that the stated odds are wrong. The History page and the "Simulate" feature on each case page exist specifically to make this gap visible, not to hide it.
